
# AbleSpace Software Tester (QA) Assignment

## Overview
This repository contains my manual QA testing assignment for AbleSpace. The purpose of the testing was to check the application's main functions, usability, and browser compatibility.

## Application Tested
- Application: AbleSpace
- URL: https://staging.ablespace.io/
- Testing type: Manual functional, exploratory, usability, and compatibility testing
- Browsers tested: Chrome and Firefox
- Test data: Fictional data only

## Scope of Testing
- Login and profile access
- Student creation and search
- Goal creation and validation
- Notes and automatic saving
- Attachment upload and download
- Family page
- Service Time page
- Browser and layout compatibility

## Assignment Sections
1. Test Plan and Scope
2. Exploratory Testing
3. Detailed Test Cases
4. Bug Reports
5. Compatibility Testing
6. Test Summary

## Files Included
- `AbleSpace_QA_Assignment.xlsx` — QA assignment report containing test results, test cases, bug reports, compatibility results, and evidence screenshots.

## Limitations
Testing was limited to the functions and browser/device views available during the test session. Not all devices, screen sizes, and input combinations were tested. Security, penetration, and load testing were not performed.
